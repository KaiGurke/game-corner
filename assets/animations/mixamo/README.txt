Mixamo animations (recursive).

Preferred core set (Locomotion Pack/):
  idle.fbx
  walking.fbx
  running.fbx
  jump.fbx

Also used when present:
  Idle Crouching.fbx / idle crouching.fbx  → crouch
  Crouch Walking.fbx                       → crouch_walk
  jump loop.fbx                            → fall

Death clips are intentionally NOT used (ragdoll planned).

Character_*.fbx skin files inside packs are ignored.
